# DeepShift OS

> A self-hosted, AI-powered business operating system — built solo to replace Notion, HubSpot, and Zapier for a French IT freelance business.

**Live:** `http://20.111.38.245:3000`

---

## Overview

DeepShift OS is a full-stack SaaS-grade application I designed and shipped from scratch, end to end. It centralizes every operational workflow of an independent IT consultant into a single coherent product: CRM pipeline, project management, invoicing, expense tracking, and AI-driven business automation.

The driving constraint was autonomy — no recurring SaaS fees, no vendor lock-in, full control over data and workflows. Everything runs on a single Azure VM provisioned with Terraform.

**Lines of code:** ~6 000+ (TypeScript / Next.js)  
**Built solo:** architecture, design, backend, frontend, infrastructure, CI/CD, AI prompting

---

## Key Features

### CRM & Prospecting
- Kanban pipeline: `LEAD → CONTACTED → SCORED → QUALIFIED → PROPOSAL_SENT → NEGOTIATION → SIGNED`
- **AI scoring** (Claude Sonnet): generates a 0–10 conversion probability score, business tags, and a recommended next action for each prospect
- **Automated outreach**: Claude drafts personalized emails per prospect profile, sent automatically via Gmail API (OAuth2)
- **Follow-up sequences**: J+3 and J+7 follow-ups generated by Claude Haiku, auto-`LOST` after 3 unanswered emails at J+10
- **Inbound email analysis**: n8n polls Gmail every 24h, Claude detects reply intent (`INTERESTED`, `NOT_INTERESTED`, `LATER`…) and updates prospect status automatically
- **Document context**: PDF/image attachments uploaded to prospect cards are passed to Claude as multimodal context during email drafting

### Project Management
- Per-client projects with milestones, tasks, and deliveries
- **AI milestone generation**: Claude Sonnet generates a structured milestone plan from an uploaded project brief
- Client delivery validation flow (OK / Needs revision)

### Finance
- Quote lifecycle: `DRAFT → SENT → ACCEPTED` — one-click conversion to invoice
- Invoice lifecycle: `UNPAID → PAID` with revenue dashboard (monthly / yearly / target)
- Prospective revenue tracking from open quotes

### Admin
- Expense tracking and SaaS subscription management
- **AI weekly review**: Claude analyzes CRM activity, pipeline, and revenue each week and generates a structured business report

## CI/CD Pipeline

```
feature/* → dev → main → Azure VM (auto-deploy)
```

| Workflow | Trigger | Steps |
|---|---|---|
| `ci.yml` | PR to `main` / `dev` | Typecheck · lint · build |
| `deploy.yml` | Push to `main` | SSH into VM → git pull → npm install → prisma migrate deploy → docker compose up |
| `reset-db.yml` | Manual | Drop + recreate database |

Migrations run automatically on every deploy against the private VM IP (`10.0.1.4`), keeping schema and code in sync without manual intervention.

## AI Automation (n8n Workflows)

| Workflow | Schedule | What it does |
|---|---|---|
| Daily outreach | Tue–Thu 9:00 | Drafts + sends a personalized email to every `SCORED` prospect |
| Follow-up J+3 / J+7 | Tue–Thu 9:00 | Sends follow-up sequences; marks `LOST` after J+10 silence |
| Gmail polling | Every 24h | Reads inbox, classifies reply intent with Claude Haiku, updates prospect status |

All workflows call internal API endpoints (`/api/cron/*`, `/api/webhooks/*`) over the private network. n8n orchestrates scheduling and retry logic; Next.js handles business logic and AI calls.

## Infrastructure

Provisioned from scratch with Terraform:

- **Azure VM** — FranceCentral, `Standard_D2s_v3` (2 vCPU / 8 GB RAM)
- **Networking** — VNet + subnet + NSG + static public IP
- **Services** — PostgreSQL 16 · n8n · Next.js — all running in Docker Compose on the same VM
- **Secrets** — injected at VM creation via `cloud-init`, never committed

```bash
cd app/cloud
terraform init && terraform apply   # full infra in ~3 minutes
```

## Technical Highlights

- **Multimodal AI** — prospect documents (PDFs, images) are stored in PostgreSQL as base64 and passed to Claude as `document`/`image` blocks during generation
- **Token efficiency** — email drafting reuses the `aiSummary` already in DB, reducing Claude calls from 2 to 1 per email
- **Robust JSON parsing** — Claude responses are extracted with a `{[\s\S]*}` regex to handle markdown-wrapped JSON reliably
- **Auto-LOST detection** — evaluated server-side on every Kanban load: 3 sent emails + 0 replies + 10 days → status flips to `LOST` automatically, no cron needed
- **Cascade deletes** — full referential integrity enforced at schema level (Prospect → Quotes, Invoices, Projects, Emails, Documents…)
